# Truck Load Management System

## Project Overview

This is a Full Stack Truck Load Management System developed using React.js and Django REST Framework. The project helps shippers post loads, drivers accept and deliver loads, and admins manage the overall system.

## Features

- User Login & Registration
- Shipper Dashboard
- Driver Dashboard
- Load Management
- Booking Management
- JWT Authentication

## Technologies Used

Frontend
- React.js
- Vite
- Axios

Backend
- Python
- Django
- Django REST Framework

Database
- SQLite

## How to Run

### Backend

cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

### Frontend

cd frontend
npm install
npm run dev
